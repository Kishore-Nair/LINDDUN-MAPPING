About MPSS

MPSS (Metric-based Product Security Scoring) is a vulnerability scoring calculator that implements the CVSS v3.1 specification with complete accuracy.

Scoring Methodology

MPSS uses the exact formulas defined in the CVSS v3.1 Specification Document published by FIRST.Org, Inc. All metric values, equations, and the Roundup function are implemented precisely as specified.

Severity Ratings

None 0.0
Low 0.1 – 3.9
Medium 4.0 – 6.9
High 7.0 – 8.9
Critical 9.0 – 10.0

Three Metric Groups

B

Base

Intrinsic vulnerability characteristics that are constant over time and across environments. Includes Exploitability and Impact sub-scores.

T

Temporal

Characteristics that change over time, such as exploit code availability, remediation status, and reporting confidence.

E

Environmental

Characteristics unique to the user's environment, including security requirements and modified base metrics.
